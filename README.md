### Overview
This project was initially created to improve my understanding of CSS3 features such as Flexbox and Grid Layout. It was a simple project at the time but rich in CSS content.

In 2025, I set a goal to review and update all my GitHub projects. As part of this initiative, I enhanced this exercise with modern tools and technologies to improve speed, performance, and functionality. Updates include the addition of Gulp, JavaScript, and Sass. Techniques like AJAX and BEM were also implemented to simplify maintenance and reduce HTTP requests to the server.

### 👀 Prerequisites

Before starting, ensure you have the following tools installed on your machine:<br/>
- [Git](https://git-scm.com) 
- A code editor like [VSCode](https://code.visualstudio.com/)
- [Node](https://nodejs.org/en)

### 🎲 Running the Project

```bash
# Clone this repository
$ git clone <https://github.com/Arthur-Ferreira/Css_Flexbox_Gridlayout_Exercise>

# Navigate to the project folder
$ cd {Your folder name}

# Install the dependecies
$ npm i

# Run the project
$ npx gulp

```
